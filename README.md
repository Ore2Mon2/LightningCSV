# LightningCSV ⚡

**巨大 CSV ファイルも一瞬で開ける、Windows 向け高速 CSV / テキストエディター**

10 GB 超のファイルもストレスなく閲覧・編集・検索・集計できます。

---

## ダウンロード・インストール

[Releases ページ](https://github.com/Ore2Mon2/LightningCSV/releases) から最新版をダウンロードしてください。

| ファイル | 説明 |
|---------|------|
| `LightningCSV_x.x.x_windows_portable.zip` | **ポータブル版** — インストール不要。zip を解凍して `LightningCSV.exe` を実行するだけで使えます |

### 動作環境

- **Windows 10 / 11**（64 ビット）
- WebView2 ランタイム（Windows 10/11 には標準搭載）

---

## 主な特徴

- **巨大ファイルでも一瞬で開く** — 10 GB のファイルも 1 秒以内に表示
- **100 万行超でもサクサクスクロール** — 必要な部分だけ読み込む仮想スクロール
- **メモリに優しい** — ファイル全体をメモリに読み込まないため、PC のメモリが少なくても大丈夫
- **SQL でデータ分析** — SELECT / WHERE / GROUP BY など、SQL クエリでデータの検索・集計が可能
- **文字コード自動判定** — UTF-8 / Shift_JIS を自動検出（手動切替も可能）
- **ダークモード対応** — ライト / ダーク / システム連動テーマ
- **日本語 / 英語 対応** — 設定から切り替え可能

## 機能一覧

### ファイル操作

- CSV / TSV / TXT / LOG など、テキスト形式のファイルを開ける
- ファイルダイアログ、または**ドラッグ＆ドロップ**で開く
- **複数ファイルをタブで同時に開ける**
- 上書き保存 / 名前を付けて保存に対応
- 閉じるときに未保存の変更があれば確認ダイアログを表示

### CSV グリッド表示

- **表計算ソフトのような見た目**で CSV データを閲覧・編集
- セルをダブルクリック or F2 キーで編集開始
- 行・列の**挿入・削除**が可能
- 列幅をドラッグで調整可能
- 右クリックのコンテキストメニューからもコピー・ペースト・行列操作が可能
- Ctrl+マウスホイールで**ズーム**（50%〜300%）

### テキスト表示

- CSV 以外のファイル（ログファイルなど）は**テキストモード**で表示
- 行番号付きで見やすく表示
- 大きなファイルもページ単位で快適に閲覧

### 検索・置換

- **Ctrl+F** で検索パネルを表示
- **Ctrl+H** で置換モードを表示
- 通常のテキスト検索と**正規表現検索**に対応
- 大文字・小文字の区別 ON/OFF
- Enter / Shift+Enter で次 / 前の検索結果に移動
- 一括置換にも対応

### 列フィルター

- 各列のヘッダーから**フィルターをかけて絞り込み**が可能
- **値の一覧から選択**してフィルター（Excel のオートフィルターのように使える）
- **条件指定フィルター** — 「〜を含む」「〜で始まる」「〜より大きい」など多彩な条件
- 複数列のフィルターを同時に適用可能（AND 条件）
- フィルター結果だけを別ファイルに保存することも可能

### 並べ替え（ソート）

- **複数列を優先順位付き**で並べ替え可能
- 昇順 / 降順、数値順 / 文字列順 / 日付順 / 文字列長順
- 空白セル（NULL）の位置を先頭 / 末尾に指定可能
- **選択範囲だけを並べ替え**ることも可能
- ドラッグ＆ドロップでソート条件の優先順位を変更

### SQL 検索・集計

- **Ctrl+Shift+S** で SQL パネルを表示
- 開いている CSV に対して SQL クエリを実行
  ```sql
  SELECT 都道府県, COUNT(*) AS 件数
  FROM data
  WHERE 金額 > 10000
  GROUP BY 都道府県
  ORDER BY 件数 DESC
  ```
- 集計結果を CSV / TSV ファイルとして保存可能
- Shift_JIS のファイルにも対応

### 編集・Undo/Redo

- セルの編集、行・列の追加・挿入・削除が可能
- **Ctrl+Z** で元に戻す、**Ctrl+Y** でやり直し
- 編集の上限回数は設定で変更可能（デフォルト 100 回）

### 保存オプション

- 保存時に以下を選択可能:
  - **区切り文字**（カンマ / タブ / カスタム）
  - **文字コード**（UTF-8 / Shift_JIS）
  - **改行コード**（CRLF / LF）
  - **クォート文字** / **ヘッダー行の有無** / **NULL の表現**

### 設定

- **Ctrl+,** で設定ダイアログを表示
- フォント・フォントサイズ・行の高さをカスタマイズ
- 先頭行をヘッダーとして扱うかどうかの切替
- デフォルトの区切り文字・文字コード・改行コードの設定
- 保存時に自動バックアップを作成する ON/OFF

## キーボードショートカット

| 操作 | ショートカット |
|------|---------------|
| ファイルを開く | `Ctrl+O` |
| 上書き保存 | `Ctrl+S` |
| 元に戻す（Undo） | `Ctrl+Z` |
| やり直し（Redo） | `Ctrl+Y` |
| 検索 | `Ctrl+F` |
| 検索＆置換 | `Ctrl+H` |
| 設定 | `Ctrl+,` |
| SQL パネル | `Ctrl+Shift+S` |
| SQL 実行 | `Ctrl+Enter`（SQL パネル内） |
| セル編集開始 | `F2` またはダブルクリック |
| セル編集確定 | `Enter` |
| セル編集キャンセル | `Escape` |
| ズーム | `Ctrl+マウスホイール` |

## 対応ファイル

| 項目 | 対応内容 |
|------|---------|
| ファイル形式 | CSV, TSV, TXT, LOG, その他テキストファイル |
| 最大ファイルサイズ | 10 GB 超 |
| 文字コード | UTF-8 / Shift_JIS（自動検出） |
| 改行コード | CRLF / LF |
| 区切り文字 | カンマ / タブ / カスタム指定 |

## 注意事項

- **Windows 専用**です（macOS / Linux には対応していません）
- 非常に大きなファイル（数 GB）を開いた場合、行インデックスの構築に数秒かかることがあります（初回のみ）
- SQL 機能は DuckDB を内蔵しており、追加のインストールは不要です
- 設定ファイルは `%APPDATA%\LightningCSV\settings.toml` に保存されます
