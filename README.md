## ダウンロード・インストール

[GitHub Releases ページ](https://github.com/Ore2Mon2/LightningCSV/releases) から最新版をダウンロードしてください。
Windows 版はコード署名済み、macOS 版は Developer ID 署名と Apple の公証（ノータリゼーション）済み。

| ファイル | 説明 |
|---------|------|
| `LightningCSV_x.x.x_windows_portable.zip` | **Windows ポータブル版** — インストール不要。zip を展開して `LightningCSV.exe` を実行するだけで使えます |
| `LightningCSV_x.x.x_macos_arm64.dmg` | **macOS 版**（Apple Silicon）— dmg を開き、`LightningCSV` を「アプリケーション」フォルダへドラッグしてください |

### 1.x からの更新（Windows ポータブル版）

- zip を展開した中身を、1.x と同じフォルダに上書きするか、任意のフォルダに置いてください（念のため、更新前に 1.x のフォルダをバックアップしておくことをおすすめします）
- 設定ファイル（`config.json`）の形式は 1.x と同じです。1.x と同じフォルダに置けば、設定がそのまま引き継がれます

## 主な特徴

- **巨大ファイルでも安定して開ける** — (10 GB まで)
- **5000 万行でもサクサクスクロール** — 必要な部分だけ読み込む仮想スクロール
- **SQL モード搭載** — SQL クエリでデータの検索・集計が可能
- **文字コード自動判定** — UTF-8 / Shift_JIS を自動検出（手動切替も可能）
- **ダークモード対応** — ライト / ダーク / システム連動テーマ
- **日本語 / 英語 対応**

## 機能一覧

### ファイル操作

- 対応テキストファイル形式 = .csv / .tsv / .txt / .log
- ドラッグ＆ドロップでのファイル読み込み
- タブ表示対応

### CSV グリッド表示

- 表計算ソフトのように CSV データを閲覧・編集
- 選択セルで Enter、ダブルクリック、F2 キーで編集
- 行・列の挿入・削除
- セル・範囲・行・列の選択、選択範囲のコピー（Excel などに貼り付けられるタブ区切り形式）
- 指定行へジャンプ — ツールバーの行番号欄に行番号を入力して Enter
- 複数セルを選択すると、ステータスバーに 件数・合計・平均・最小・最大 を表示（列全体など大きな範囲も全件を集計）
- 列幅をドラッグで調整
- 右クリックのコンテキストメニューからもコピー・ペースト・行列操作

### テキスト表示

- ツールバーの切替ボタンで、グリッド表示とテキストモードを切り替え  
  （テキストモードでは編集不可）
- 行番号付きで見やすく表示

### 検索・置換

- Ctrl+F で検索パネルを表示
- Ctrl+H（macOS は ⌥⌘F）で置換モードを表示
- 通常のテキスト検索と正規表現検索に対応
- 大文字・小文字の区別 ON/OFF
- Enter / Shift+Enter で次 / 前の検索結果に移動
- 一括置換にも対応

### 列フィルター

- 各列のヘッダーからフィルターをかけて絞り込み
- 値の一覧から選択してフィルター（Excel のオートフィルターのように使える）
- 条件指定フィルター — 「〜を含む」「〜で始まる」「〜より大きい」など多彩な条件
- 複数列のフィルターを同時に適用可能（AND 条件）
- 絞り込んだ行（または絞り込まれなかった行）の一括削除
- フィルター結果だけを別ファイルに保存

### 並べ替え（ソート）

- 複数列を優先順位付きで並べ替え
- 昇順 / 降順、数値順 / 文字列順 / 日付順 / 文字列長順
- 空白セル（NULL）の位置を先頭 / 末尾に指定可能
- ドラッグ＆ドロップでソート条件の優先順位を変更

### SQL 検索・集計

- Ctrl+Shift+S で SQL パネル表示
- 開いている CSV を `data` というテーブル名で参照し、SQL クエリを実行
  ```sql
  SELECT 都道府県, COUNT(*) AS 件数
  FROM data
  WHERE 金額 > 10000
  GROUP BY 都道府県
  ORDER BY 件数 DESC
  ```
- 結果のコピー
- 集計結果を CSV / TSV などのファイルとして保存

### 編集・Undo/Redo

- セルの編集、行・列の追加・挿入・削除が可能
- 元に戻せる回数は設定で変更可能（10〜100 回、デフォルト 100 回）

### 保存オプション

- フィルター結果・SQL 結果を保存するときに以下を選択可能（前回選んだ内容を記憶）:
  - 拡張子（.csv / .tsv / .txt）
  - 区切り文字（カンマ / タブ / セミコロン / パイプ / スペース）
  - 文字コード（UTF-8 / UTF-8 BOM 付き / Shift_JIS）
  - 改行コード（CRLF / LF）
  - クォート文字 / ヘッダー行の有無 / NULL の表現

### 設定

- 表示言語（日本語 / 英語）・テーマ（ライト / ダーク / システム連動）
- フォント・フォントサイズ・行の高さをカスタマイズ
- 先頭行をヘッダーとして扱うかどうかの切替
- デフォルトの区切り文字・文字コード・改行コードの設定
- 起動時に新しいバージョンがあるかを確認、通知

## キーボードショートカット

| 操作 | Windows | macOS |
|------|---------|-------|
| ファイルを開く | `Ctrl+O` | `⌘O` |
| 上書き保存 | `Ctrl+S` | `⌘S` |
| コピー | `Ctrl+C` | `⌘C` |
| 元に戻す（Undo） | `Ctrl+Z` | `⌘Z` |
| やり直し（Redo） | `Ctrl+Y` / `Ctrl+Shift+Z` | `⌘Y` / `⇧⌘Z` |
| 検索 | `Ctrl+F` | `⌘F` |
| 検索＆置換 | `Ctrl+H` | `⌥⌘F` |
| 設定 | `Ctrl+,` | `⌘,` |
| SQL パネル | `Ctrl+Shift+S` | `⇧⌘S` |
| SQL 実行 | `Ctrl+Enter`（SQL パネル内） | `⌘Enter`（SQL パネル内） |
| セル編集開始 | `F2` またはダブルクリック | `F2` またはダブルクリック |
| セル編集確定 | `Enter` | `Enter` |
| セル編集キャンセル | `Escape` | `Escape` |

## 対応ファイル

| 項目 | 対応内容 |
|------|---------|
| ファイル形式 | CSV, TSV, TXT, LOG (テキストファイル)|
| 最大ファイルサイズ | 10 GB |
| 文字コード | UTF-8 / Shift_JIS（自動検出） |
| 改行コード | CRLF / LF |
| 区切り文字 | カンマ / タブ / カスタム指定 |

## 設定ファイル（`config.json`）の保存先:
  - Windows ポータブル版: `LightningCSV.exe` と同じフォルダ
  - macOS: `~/Library/Application Support/LightningCSV/config.json`
